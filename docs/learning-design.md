# 2026 포켓볼 — 학습·체험 설계 문서

경남수학문화관 「대칭으로 보는 당구」(사각 터치 당구대) 및 타원 당구대 교구를
웹 시뮬레이터로 옮기기 위한 기준 문서.

- 대상: **초등 고학년 ~ 중학생** (전시 관람객)
- 목표: 개념을 **체험으로 재미있게** 경험한다. 증명·공식·고등 개념은 다루지 않는다.
- 구성: ① 네모 당구대 미션 ② 타원 당구대 마법 ③ 포켓볼 대결(2인, 재미 요소)

---

## 1. 핵심 경험 (6가지)

### 네모 당구대

| # | 학생이 경험하는 것 | 한 줄 깨달음 |
|---|---|---|
| ① | 치기 전에 "어디로 갈까?" 찍고 → 쳐보고 → 맞았나 확인 | 쿠션에 맞으면 **거울처럼** 튄다 |
| ② | 빨간 공을 쿠션 너머로 **뒤집어(대칭) 놓고** 직선으로 겨냥하면 맞는다 | 휘는 길도 뒤집으면 **직선 하나**가 된다 |
| ③ | 2쿠션, 3쿠션도 같은 방법으로 성공 | 대칭을 한 번 더, 또 한 번 더 — **규칙은 똑같다** |

### 타원 당구대

| # | 학생이 경험하는 것 | 한 줄 깨달음 |
|---|---|---|
| ④ | 노란 공(초점)을 **아무 방향으로** 쳐도 빨간 공에 맞는다 | 이 테이블엔 **마법의 점** 두 개가 있다 |
| ⑤ | 초점이 **아닌** 곳에서 치면 안 맞는다 | 마법은 **딱 그 자리**에서만 통한다 |
| ⑥ | 어느 방향으로 쳐도 공이 굴러간 거리가 똑같다 (막대로 표시) | 길은 달라도 **거리는 항상 같다** |

### 두 테이블을 잇는 경험

같은 공, 같은 치기인데 **테이블 모양이 다르니 결과가 달라진다.**
네모에선 "내가 계산해서 맞추는 것", 타원에선 "테이블이 알아서 맞춰주는 것".

## 2. 의도적으로 제외한 것

| 제외 | 이유 |
|---|---|
| 좌표 대칭 규칙 (x, −y) 등 | 고1 내용. 체험엔 그림 대칭이면 충분 |
| 최단경로·페르마 원리 | 설명 없이는 안 보이고, 설명하면 강의가 됨 |
| 유리수/무리수 기울기, 주기 궤도 | 이론 없이는 의미가 안 생김 |
| 오차 민감도 정량 실험 (0.1° 조정) | 초·중생에게는 '귀찮음'으로만 남음 |
| 이심률, 접선·법선 | 고2 기하 |
| 포락선(caustic) 이론 | 아름답지만 이해 불가 → '눈요기 모드'로 형태만 남김 |
| 마찰·회전 on/off 비교 | 모델링 논의는 고등 이상 |

---

## 3. 이론 없이 '보기만 해도' 되는 재미 요소

- **원 → 타원 슬라이더**: 동그라미를 납작하게 만들면 마법의 점 두 개가 벌어지고, 다시 동그라미로 만들면 한 점으로 합쳐진다.
- **불꽃놀이 모드(타원)**: 초점에서 100방향으로 동시에 쏘면 전부 빨간 공에 모인다.
- **엉뚱한 곳에서 100방향 쏘기**: 절대 모이지 않고 예쁜 무늬가 생긴다. 이름은 붙이지 않고 "왜 무늬가 생길까?"만 남긴다.
- **네모 테이블에서 계속 튕기기**: 힘껏 치면 수십 번 튕기며 지그재그 무늬가 그려진다.

## 4. 포켓볼 대결 (2인 교대, 재미 요소)

교육 미션과 별개로, 친구·가족과 **번갈아 치는 포켓볼 게임**. 같은 물리 엔진을 그대로 쓴다.

### 규칙 (두 가지 난이도)

| 모드 | 대상 | 규칙 |
|---|---|---|
| **점수 모드** (기본) | 초등 | 아무 공이나 넣으면 1점. 넣으면 한 번 더, 못 넣으면 교대. 공이 다 들어가면 점수 많은 쪽 승리. |
| **8볼 모드** | 중등 | 단색 / 줄무늬 그룹을 나눠 갖고, 자기 그룹을 다 넣은 뒤 8번을 넣으면 승리. 8번을 먼저 넣으면 패배. |

공통:
- 흰 공이 들어가면 **파울** → 상대 턴, 흰 공을 원하는 곳에 놓고 시작
- 시작 시 자동 랙 배치, 첫 샷(브레이크)은 가위바위보 화면으로 선공 결정
- 공 수 옵션: 15개(기본) / 9개(빠른 게임)

### 화면·조작

- **턴 표시를 크게**: 화면 상단 "🔵 1번 친구 차례 / 🔴 2번 친구 차례", 색으로 구분
- 조작: 흰 공을 드래그해 방향·세기 결정, 손을 떼면 발사 (터치 우선)
- **조준선**: 흰 공이 처음 맞을 지점까지의 선 + 맞은 공이 갈 짧은 방향 화살표 (초등 기본 ON, 8볼 모드 기본 OFF)
- **"거울 켜기"** 버튼은 여기서도 동작 → 쿠션 샷 힌트. 교육 미션에서 배운 대칭이 게임에서 통한다는 걸 자연스럽게 연결
- 점수판, 넣은 공 아이콘 나열, 리플레이

### 전시 운영을 위한 장치

- **턴 제한 시간** 30초(옵션) — 회전율 확보
- **게임 시간 제한** 5분(옵션) — 종료 시 점수 많은 쪽 승리
- 60초 무조작 시 홈 화면으로 자동 복귀
- 게임 종료 화면에서 "다시 하기 / 홈으로" 두 버튼만

## 5. 기능 목록 (초·중 기준으로 압축)

| 목표 | 기능 | 비고 |
|---|---|---|
| ① 예측→확인 | 치기 전 **도착 예상 지점 찍기**, 실행 후 "거의 맞았어요! / 조금 빗나갔어요" 피드백 | 각도 숫자 X, 거리감 피드백 O |
| ② 대칭 발견 | **"거울 켜기" 버튼** — 빨간 공의 대칭 그림자가 쿠션 너머에 나타남 | 처음엔 꺼두고 스스로 해보게 |
| ③ 단계 확장 | 1쿠션 → 2쿠션 → 3쿠션 **미션 레벨**, 별 획득 | 배너의 ★★★ 그대로 활용 |
| ④⑤ 초점 체험 | 노란 공을 **드래그해서 아무 데나** 놓고 치기, 초점 위에 있으면 반짝임 | 초점 자리에서만 '마법' |
| ⑥ 거리 불변 | 굴러간 거리를 **막대 하나**로 표시 — 방향 바꿔도 막대 길이가 안 변함 | 숫자보다 막대가 직관적 |
| 조작 | **드래그로 방향, 놓으면 발사**, 터치 우선 | 전시 터치테이블 그대로 |
| 재미 | 불꽃놀이 모드, 원↔타원 슬라이더, 리플레이 | 3장 |
| 대결 | 2인 교대 포켓볼(점수 모드 / 8볼 모드) | 4장 |
| 공통 | 슬로우 모션, 다시 하기, 궤적 잔상, 무조작 자동 복귀 | |

## 6. 화면 구조

```
홈
├─ 네모 당구대 미션   (★1 1쿠션 → ★2 2쿠션 → ★3 3쿠션, 자유 연습)
├─ 타원 당구대 마법   (마법의 점 → 아무 데서나 → 거리 막대 → 불꽃놀이 / 슬라이더)
└─ 포켓볼 대결        (점수 모드 / 8볼 모드, 15개 / 9개)
```

세 모드는 공을 굴리고 쿠션·공끼리 부딪히는 **하나의 물리 엔진**을 공유한다.
차이는 경계(직선 / 타원), 포켓 유무, 규칙 레이어뿐이다.
