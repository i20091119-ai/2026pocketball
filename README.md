# 2026 포켓볼 — 대칭으로 보는 당구

경남수학문화관 「대칭으로 보는 당구」·타원 당구대 교구의 웹 시뮬레이터.
초·중학생이 **체험으로** 대칭과 타원의 초점을 느끼는 것이 목표입니다.

| 모드 | 내용 |
|---|---|
| 네모 당구대 미션 | 1·2·3쿠션 미션, 🪞 거울(대칭) 보기, 🎯 예측 놀이 |
| 타원 당구대 마법 | 마법의 점(초점)에서 치면 무조건 맞는다, 굴러간 거리 막대, 🌈 모든 경로 보기, ○↔⬭ 슬라이더 |
| 포켓볼 대결 | 2인 교대 — 점수 모드 / 8볼 모드, 15개 / 9개, 시간 제한 옵션 |

## 실행

빌드 도구가 없습니다. `index.html`을 브라우저에서 열면 바로 실행됩니다 (파일 더블클릭 OK).
전시 PC에서는 전체화면(F11)으로 열어 두세요. 90초 동안 조작이 없으면 홈으로 돌아갑니다.

- 조작: 공이 아닌 곳을 **끌어서** 방향·세기를 정하고 손을 떼면 발사. 공을 끌면 위치 이동.
- 터치스크린 우선으로 만들었고 마우스도 됩니다.

## 윈도우 전시 PC에서 로컬로 쓰기

인터넷이 없어도 됩니다. 글꼴·효과음·로고가 전부 저장소 안에 들어 있습니다.

1. **내려받기**: GitHub 저장소 페이지 → 초록색 `Code` 버튼 → `Download ZIP`
   (또는 https://github.com/i20091119-ai/2026pocketball/archive/refs/heads/main.zip)
2. **압축 풀기**: 예) `C:\당구` 처럼 한글·공백이 없는 짧은 경로가 안전합니다.
3. **실행**: 폴더 안의 `실행-엣지.bat`(엣지) 또는 `실행-크롬.bat`(크롬)을 더블클릭
   → 전체화면 키오스크 모드로 열립니다. 종료는 `Alt + F4`.
   그냥 `index.html`을 더블클릭해도 되지만, 이때는 브라우저 주소창이 보이고 F11로 전체화면을 켜야 합니다.
4. **전시 종료(터치스크린만 있을 때)**: 어느 화면에서든 **⌂ 홈 버튼(홈 화면에서는 로고)을 3초간 길게 누르면** 관리자 창이 열리고,
   `⏻ 전시 종료`를 누르면 창이 닫힙니다. 배치 파일로 실행했을 때만 동작합니다(브라우저 규칙: 이동 기록이 하나인 창만 스크립트로 닫을 수 있음).
5. **부팅 시 자동 실행**(선택): `Win + R` → `shell:startup` → 열린 폴더에 `실행-엣지.bat`의 바로가기를 넣어 둡니다.

전시 PC 설정 권장:
- 전원 옵션에서 화면 끄기·절전을 **안 함**으로
- 터치 모니터라면 Windows 설정 → 태블릿 → 화면 가장자리 스와이프 제스처 끄기
- 첫 터치 뒤에 소리가 켜집니다(브라우저 정책). 소리는 홈 화면 🔊 버튼으로 끌 수 있습니다.

업데이트는 새 ZIP을 받아 폴더를 통째로 바꾸면 됩니다.

## 웹 배포 (GitHub Pages)

저장소의 **기본 브랜치에 푸시하면 GitHub Pages가 자동으로 배포**합니다 (Settings → Pages, "Deploy from a branch").
빌드 과정이 없으므로 별도 워크플로는 필요 없습니다. 푸시 후 1분 안팎이면 반영됩니다.

- 주소: https://i20091119-ai.github.io/2026pocketball/
- 배포 상태: 저장소 Actions 탭의 "pages build and deployment"

## 글꼴

`assets/fonts/`에 Jua(제목·버튼)와 Gowun Dodum(본문)을 woff2로 포함해 인터넷 없이도 같은 모양으로 보입니다.
두 글꼴 모두 SIL Open Font License(같은 폴더의 `OFL-*.txt`).

## 효과음

`assets/sounds/*.mp3` 17종은 `js/sound.js`의 레시피(Web Audio 합성)로 직접 제작했고,
파일 열기·오프라인에서도 재생되도록 `js/sounds-data.js`에 base64로 내장되어 있다(합계 약 150 KB).
샘플을 못 불러오면 같은 레시피로 즉석 합성한다. 홈 화면의 🔊 버튼으로 전체 끄기.

## 구조

```
index.html          화면(홈·세 모드)과 스크립트 로드
css/style.css
js/physics.js       공·쿠션(사각/타원)·포켓 물리 — 세 모드 공유
js/render.js        캔버스 그리기 도우미
js/app.js           화면 전환, 루프, 뷰 변환, 입력, 소리, 무조작 복귀
js/mode-rect.js     네모 당구대 미션
js/mode-ellipse.js  타원 당구대 마법
js/mode-pocket.js   포켓볼 대결
docs/learning-design.md  학습·체험 설계 기준 문서
```

쿠션 반사는 **입사각 = 반사각**을 정확히 지키고(에너지 손실은 속도 전체에만 적용),
타원의 초점은 공 중심이 움직이는 타원 기준으로 계산해 "초점에서 치면 반드시 맞는다"가 시뮬레이터 안에서 정확히 성립합니다.
