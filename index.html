🔧 관리자

홈 버튼이나 로고를 3초간 길게 누르면 열려요.

창이 닫히지 않으면: 화면 왼쪽 가장자리에서 안쪽으로 쓸어넘긴 뒤(작업 보기) 이 창의 ✕를 누르세요. 키보드가 있으면 Alt + F4.

▭ 네모 당구대 미션

  1. 👆
    화면을 새총처럼 당겼다 놓으면 발사! 공은 당긴 반대쪽으로 날아가요. 멀리 당길수록 세게.
  2. ✋
    공을 톡 누르면 집어 들고, 놓을 곳을 다시 누르면 옮겨져요. 빨간 공은 끌어서도 옮길 수 있어요.
  3. ⭐
    쿠션(벽)에 정해진 횟수만큼 맞히고 빨간 공을 맞히면 별을 받아요.
  4. 🪞
    어려우면 거울 켜기! 빨간 공의 거울 그림자를 향해 똑바로 치면 돼요.
  5. 🎯
    예측 놀이: 공이 어디로 튈지 먼저 찍고, 진짜 그런지 확인해요.

⬭ 타원 당구대 마법

  1. ✨
    타원 테이블에는 반짝이는 마법의 점이 두 개 있어요. 노란 공과 빨간 공이 그 위에 놓여 있어요.
  2. 👆
    화면을 새총처럼 당겼다 놓으면 노란 공이 당긴 반대쪽으로 날아가요. 아무 방향이나 골라 보세요!
  3. 🎯
    어느 방향으로 쳐도 쿠션에 맞고 빨간 공으로 가요. 정말인지 여러 방향으로 확인해 보세요.
  4. 📏
    아래 막대는 공이 굴러간 거리예요. 방향이 달라도 길이가 똑같을까요?
  5. 🔍
    노란 공을 톡 눌러 집어서 마법의 점이 아닌 곳에 놓고 치면 어떻게 될까요? 모든 경로 보기와 동그라미 슬라이더도 눌러 보세요!

🎱 포켓볼 대결

  1. 👫
    두 명이 번갈아 쳐요. 위에 누구 차례인지 나와요.
  2. 👆
    화면을 새총처럼 당겼다 놓으면 흰 공이 당긴 반대쪽으로 날아가요. 멀리 당길수록 세게!
  3. 🕳️
    공을 구멍에 넣으면 한 번 더. 못 넣으면 친구 차례.
  4. ⚠️
    흰 공이 빠지면 파울! 친구가 흰 공을 원하는 곳에 놓고 쳐요.
  5. 🏆
    점수 모드는 많이 넣은 쪽이, 8볼 모드는 자기 공을 다 넣고 8번을 마지막에 넣는 쪽이 승리!
